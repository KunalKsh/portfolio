#                          MACHINE LEARNING

TYPES OF ML-

1.SUPERVISED LEARNING

2.UNSUPERVISED LEARNING

3.REINFORCEMENT LEARNING

4.GENERATIVE AI



* **SUPERVISED LEARNING** - THIS MODEL CAN MAKE PREDICTIONS AFTER SEEING LOTS OF DATA WITH CORRECT ANSWERS AND THEN DISCOVERING THE CONNECTIONS BETWEEN ELEMENTS IN THE DATA THAT PRODUCES CORRECT ANSWERS. "TWO OF THE MOST COMMON USE FOR SUPERVISED LEARNINGS ARE REGRESSION \& CLASSIFICATION"



SUPREVISED LEARNING OUTPUTS - 1. **REGRESSION** 2. **BINARY CLASSIFICATION** 3. **MULTICLASS CLASSIFICATION**



REGRESSION MODEL - PREDICTS A NUMERIC VALUE. EX-A WEATHER MODEL PREDICTS THE AMOUNT OF RAIN



CLASSIFICATION- IT PREDICTS THE LIKELIHOOD THAT SOMETHING BELONGS TO A CATEGORY. THE MODEL OUTPUT OF A VALUE IS SOMETHING BELONGING TO PARTICULAR CATEGORY.

CLASSIFICATION MODELS ARE DIVIDED IN TWO GROUPS - 1.Binary Classification 2.Multiclass classification

 1. Binary Classification - TRUE OR FALSE (Rain or No Rain)

 2. Multiclass Classification - Multiple Possible Outcomes (Rain, Hail, Snow, Sleet)



* **UNSURPERVISED LEARNING** - THIS MODEL MAKE PREDICTIONS BY BEING GIVEN DATA THAT DOES NOT CONTAIN ANY CORRECT ANSWERS. AN UNSUPERVISED LEARNING MODEL'S GOAL IS TO IDENTIFY MEANINGFUL PATTERNS AMONG THE DATA. IT MUST INFER IT'S OWN RULE.

CLUSTERING - A COMMONLY USED UNSUPERVISED LEARNING MODEL EMPLOYS CLUSTERING TECHNIQUE. IN CLUSTERING CATEGORIES AREN'T PRE-DEFINED BY THE USER.



* **REINFORCEMENT LEARNING** - THIS MODEL MAKES PREDICTIONS BY GETTING REWARDS OR PENALTIES BASED ON ACTIONS PERFOMED WITHIN AN ENVIRONMENT. IT GENERATES A POLICY THAT DEFINES THE BEST STRATEGY FOR GETTING THE MOST REWARDS. (ROBOTS)



* **GENERATIVE AI** - IT'S A CLASS OF MODELS THAT CREATES CONTENTS FROM USER INPUTS. IT TAKES VARIETY OF INPUTS AND CREATES A VARIETY OF OUTPUTS.

"TYPE-OF-INPUT--->TYPE-OF-OUTPUT". TEXT-TO-TEXT-IMAGE-VIDEO-CODE-SPEECH. IMAGE-TO-TEXT. GEN-AI LEARNS PATTERNS IN DATA TO PRODUCE NEW BUT SIMILAR DATA.

INITIALLY GENERATIVE MODELS ARE TRAINED USING AN UNSUPERVISED APPROACH.





**SUPERVISED LEARNING-**



CORE CONCEPTS - 1.DATA 2.MODEL 3.TRAINING 4.EVALUATING 5.INFERENCE



1. **DATA** - DRIVING FORCE OF ML. FORMS OF DATA - WORDS, TABLES, PIXELS, WAVEFORMS. STORED IN DATAFRAMES. EG - IMAGES OF CAT, HOUSING INFO, WEATHER INFO

DATA CONTAINS FEATURES AND A LABEL. FEATURES ARE THE VALUE THAT A SUPERVISED MODELS USES TO PREDICT THE LABEL. LABEL IS THE ANSWER.

LABELLED EG.- FEATURES--->LABEL

UNLABELLED EG.- ONLY FEATURES--->NO LABLE. CREATING THE MODEL--->PREDICTS THE LABELS

DATASET CHARACTERISTICS- DATASET IS CHARACTERIZED BY ITS SIZE \& DIVERSITY. SIZE INDICATES THE NUMBER OF EXAMPLES. DIVERSITY INDICATES THE RANGE.

BOTH THE SIZE AND DIVERSITY OF THE DATA WOULD BE IDEAL FOR THE MODEL. DEPENDENCY OF THE OBJECTIVE FUNCTION ON THE DEPENDANT VARIABLES SHOULD BE PRESENT.



2\. **MODEL** - IT IS THE COMPLEX COLLECTION OF NUMBERS THAT DEFINE THE MATHEMATICAL RELATIONSHIP FROM SPECIFIC INPUT FEATURES PATTERNS TO SPECIFIC OUTPUT LABEL VALUES.

MODEL DISCOVERS THESE PATTERNS THROUGH TRAINING.



3\. **TRAINING** - SUPERVISED MODEL SHOULD BE TRAINED BEFORE MAKING PREDICTIONS. TRAINING THE MODEL

---> 1. DATASET WITH LABELED EXAMPELS.

---> 2. MODEL'S GOAL TO ACHIEVE BEST SOLUTION FOR PREDICTING THE LABELS FROM THE FEATURES.

---> 3. MODEL FINDS THE BEST SOLUTION BY COMPARING IT'S PREDICTED VALUE TO THE LABEL'S ACTUAL VALUE

---> 4. BASE ON THE DIFFERENCE OF PREDICTED VALUE \& LABEL'S ACTUAL VALUE LOSS IS CALCULATED

---->5. THE MODEL THEN UPDATE'S ITSELF

---->6. MODEL LEARNS THE MATHEMATICAL RELATIONSHIP BETWEEN FEATURES \& LABEL TO BEST PREDICT ON UNSEEN DATA

ML PRACTITIONERS CAN MAKE THE SUBTLE ADJUSTMENTS TO THE CONFIGURATIONS AND FEATURES TO BEST PREDICT THE OUTCOME



4\. **EVALUATING** AN ML MODEL BY COMPARING IT'S PRECITIONS TO THE ACTUAL VALUE



5\. **INFERENCE** - ONCE WE ARE SATISFIED BY THE PREDICTION OF THE MODEL THEN WE CAN MAKE PREDICTIONS ON UNLABELLED EXAMPLES CALLED INFERENCES.



### LINEAR REGRESSION



LINEAR REGRESSION IS A STATISTICAL TECHNIQUE USED TO FIND THE RELATIONSHIP BETWEEN VARIABLES. IT FINDS THE RELATIONSHIP BETWEEN THE FEATURES AND LABELS.

FOR EG.-FOR CAR FUEL'S EFFICIENCY BASED ON THEIR WEIGHT AND MILES



|  POUNDS  |  MILES |

|-------------------|

|  3.5	   |  18    |

|  3.69	   |  15    |

|  3.44    |  18    |

|  3.43	   |  16    |

|  4.34	   |  15    |

|  4.42	   |  14    |

|  2.37    |  24    |



-PLOTTING A GRAPH WOULD GIVE AN INSIGHT THAT THE WEIGHT OF THE CAR AFFECTS THE FUEL'S EFFICIENCY AS THE MILES DECREASE

-TRAIN THE MODEL BY DRAWING A BEST FIT LINE THROUGH THE POINTS



**LINEAR REGRESSION EQUATION-**

MODEL EQ.- y= mx + b

* y is the miles per gallon-the value we want to predict.
* m is the slope of the line.
* x is pounds - input value.
* b is the y - intercept.



**ML EQUATION FOR A LINEAR REGRESSION** - y'= b + w1x1

* y' is the predicted label-the output.
* b(w0) is the bias of the model. Bias is the concept as the y-intercept in the algebraic eqn. Bias is a parameter of model; calculated during training.
* w1 is the weight of the feature. Weight is the concept as the slope m in the algebraic eqn. for a line. It's a parameter calculated during training.
* x1 is the feature-the input.
* y'(prediction) = b(bias) + w1(weight)x1(feature value) \[b,w1 - CALCULATED DURING TRAINING]



MODELS WITH MULTIPLE FEATURES -

* y' = b + w1x1 + w2x2 + w3x3 + w4x4 + w5x5

x1 - POUNDS

x2 - ENGINE DISPLACEMENT

x3 - ACCELERATION

x4 - NUMBER OF CYLINDERS

x5 - HORSEPOWER



**LOSS -** IT'S A NUMERICAL METRIC THAT DESCRIBES HOW WRONG A MODEL'S PREDICTIONS ARE. LOSS MEASURES THE DISTANCE BETWEEN THE MODEL'S PREDICTIONS \& THE ACTUAL LABELS. THE GOAL OF TRAINING A MODEL IS TO MINIMIZE THE LOSS, REDUCING IT TO ITS LOWEST POSSIBLE VALUE.



**DISTANCE OF LOSS** - IN STATISTICS \& ML, LOSS MEASURES THE DIFFERENCE BETWEEN THE PREDICTED \& ACTUAL VALUE. ACTUAL VALUE= 5, PREDICTED VALUE= 3, LOSS=3-5=-2

REMOVE THE SIGN - 1. ABSOLUTE VALUE OF THE DIFFERENCE 2. SQUARE THE DIFFERENCE



TYPE OF LOSS-

1. **L1 LOSS** - SUM OF ABSOLUTE VALUE OF THE DIFFERENCE - Σ|ACTUAL VALUE - PREDICTED VALUE|
2. **MEAN ABSOLUTE ERROR(MAE)** - AVERAGE OF L1 ACROSS N EXAMPLES - 1/N Σ|ACTUAL VALUE - PREDICTED VALUE|
3. **L2 LOSS** - SUM OF SQUARED DIFFERENCE BETWEEN THE PREDICTED VALUES \& THE ACTUAL VALUE - |(ACTUAL VALUE - PREDICTED VALUE)^2|
4. **MEAN SQUARED ERROR(MSE)** - THE AVERAGE OF L2 ACROSS N EXAMPLES -  1/N Σ|(ACTUAL VALUE - PREDICTED VALUE)^2|



CALCULATING LOSS-



Q.> WEIGHT = -4.6, BIAS = 34 (THE MODEL PREDICTS THAT A 2,370(2.37)-POUND CARE GETS 23.1 BUT IT ACTUALLY GETS 26 MILES, WE WOULD CALCULATE L2 AS FOLLOWS -



* PREDICTION = BIAS + (WEIGHT\*FEATURE VALUE) = 34 + (-4.6\*2.37) = 23.1 (2.37 USED AS PER THE GRAPH THAT ARE SCALED TO 1000s OF POUNDS)
* ACTUAL VALUE = LABEL = 26
* L2 LOSS  = (ACTUAL VALUE-PREDICTED VALUE)^2 = (26-23.1)^2 = 8.41

LOSS FOR THAT SINGLE DATA POINT IS 8.41



**CHOOSING A LOSS-**

DECIDING WHETHER TO USE MEAN ABSOLUTE ERROR(MAE) OR MEAN SQUARE ERROR(MSE) DEPENDS ON THE DATASET AND THE WAY WE WANT TO HANDLE CERTAIN PREDICTIONS. MOST FEATURE VALUES IN A DATASET FALLS WITHIN A DISTINCT RANGE. OUTLIER CAN BE REFERRED TO HOW FAR THE MODEL'S PREDICTION VALUE ARE FROM THE REAL VALUES. MODEL TRAINED USING MEAN STANDARD ERROR(MSE) MOVES THE MODEL CLOSER TO THE OUTLIERS. MODEL TRAINED USING MEAN ABSOLUTE ERROR MOVES THE MODEL FARTHER FROM THE OUTLIERS.

1. **MSE -** THE MODEL IS CLOSER TO THE OUTLIERS BUT FURTHER AWAY FROM THE DATA POINTS
2. **MAE -** THE MODEL IS FARTHER FROM THE OUTLIER BUT CLOSER TO THE MOST OF THE DATA POINTS



**GRADIENT DESCENT -** IT IS A MATHEMATICAL TECHNIQUE THAT ITERATIVELY FINDS THE WEIGHTS AND THE BIAS THAT PRODUCE THE MODEL WITH THE LOWEST LOSS.

THE MODEL BEGINS TRAINING WITH RANDOMIZED WEIGHTS AND BIASES NEAR ZERO, AND THEN REPEATS THE FOLLOWING STEP:

1. CALCULATE THE LOSS WITH CURRENT WEIGHT AND BIAS
2. DETERMINE THE DIRECTION TO MOVE THE WEIGHTS AND BIAS THAT REDUCES LOSS
3. MOVE THE WEIGHT AND BIAS VALUES A SMALL AMOUNT IN THE DIRECTION THAT REDUCES LOSS
4. RETURN THE STEP ONE AND REPEAT THE PROCESS UNTIL THE MODEL CAN'T REDUCE THE LOSS ANY FURTHER



**EXAMPLE-**



|  POUNDS  |  MILES |

|-------------------|

|  3.5	   |  18    |

|  3.69	   |  15    |

|  3.44    |  18    |

|  3.43	   |  16    |

|  4.34	   |  15    |

|  4.42	   |  14    |

|  2.37    |  24    |



1. THE MODEL STARTS TRAINING BY SETTING THE WEIGHT \& BIAS TO ZERO ---> WEIGHT = 0, BIAS = 0, y = 0 + 0(x1)

2\. CALCULATE MSE LOSS WITH CURRENT MODEL PARAMETER ---> LOSS = ((18-0)^2 + (15-0)^2 + ............+(24-0)^2)/7 = 303.71

3\. CALCULATE THE SLOPE OF THE TANGENT TO LOSS FUNCTION AT EACH WEIGHT \& BIAS - WEIGHT SLOPE = -119.7, BIAS SLOPE = -34.3(**WEIGHT DERIVATIVE,BIAS DERIVATIVE**)

4\. MOVE A SMALL AMOUNT IN THE DIRECTION OF THE NEGATIVE SLOPE TO NEXT WEIGHT \& BIAS -

\[NEW WEIGHT = OLD WEIGHT - (SMALL AMOUNT \* WEIGHT SLOPE)] ; \[NEW BIAS = OLD BIAS -(SMALL AMOUNT)\*(BIAS SLOPE)]



Iteration Weight Bias	Loss (MSE)

1	   0	  0	303.71

2	  1.20	 0.34	170.84

3	  2.05	 0.59	103.17

4	  2.66	 0.78	68.70

5	  3.09	 0.91	51.13

6	  3.40	 1.01	42.17



MODEL IS TRAINED UNTIL IT CONVERGES. GRADIENT DESCENT HAS FOUND THE WIEGHT \& BIAS THAT NEARLY MINIMIZE THE LOSS.TRAIN THE MODEL UNTIL THE LOSS STABILIZE'S.



* **MODEL CONVERGENCE \& LOSS CURVES -** WHEN TRAINING A MODEL, WE WILL OFTEN LOOK AT A LOSS CURVE TO DETERMINE IF THE MODEL HAS CONVERGED.
* **CONVERGENCE \& CONVEX FUNCTIONS** -  THE LOSS FUNCTIONS FOR LINEAR MODELS ALWAYS PRODUCES A CONVEX SURFACE. SO WHEN A LINEAR REGRESION MODEL CONVERGES, WE CAN SUMMARIZE THAT THE MODEL FOUND THE WEIGHTS \& BIAS THAT MINIMIZE'S LOSS. \[USING 3D GRAPH ---> FIND THE OPTIMAL BIAS, WEIGHT \& LOSS(PLOTLY)]



**HYPERPARAMETERS -** THEY ARE VARIABLES THAT CONTROL DIFFERENT ASPECTS OF TRAINING. THREE COMMON HYPERPARAMETERS ARE-

* LEARNING RATE
* BATCH SIZE
* EPOCHS



PARAMETERS ARE THE VARIABLES, LIKE THE WEIGHT \& BIAS THAT ARE PART OF THE MODEL ITSELF AND ARE CALCULATED DURING TRAINING. HOWEVER, HYPERPARAMETERS ARE VALUES THAT YOU CONTROL.



**LEARNING RATE -** LEARNING RATE IS A FLOATING POINT NUMBER THAT IS SET TO DETERMINE HOW QUICKLY THE MODEL CONVERGES.

* LEARNING RATE IS TOO LOW, THE MODEL CAN TAKE A LONG TIME TO CONVERGE.
* LEARNING RATE IS TOO HIGH, THE MODEL CAN NEVER CONVERGES, BUT INSTEAD BOUNCES AROUND THE WEIGHTS \& BIAS THAT MINIMIZE THE LOSS.



LEARNING RATE --> DETERMINES THE MAGNITUDE OF THE CHANGES TO MAKE TO THE WEIGHTS \& BIAS --> GRADIENT DESCENT PROCESS

MODEL ---> (GRADIENT DESCENT)\*(LEARNING RATE) = MODEL'S PARAMETER (WEIGHT \& BIAS) ---> NEXT ITERATON

GRADIENT DESCENT --> SMALL AMOUNT TO MOVE IN THE DIRECTION OF NEGATIVE SLOPE REFERS TO THE LEARNING RATE.

DIFFERENCE BETWEEN THE OLD MODEL PARAMETER \& NEW MODEL PARAMETER IS PROPORTIONAL TO THE SLOPE OF THE LOSS FUNCTION.

EXAMPLE --> GRADIENT'S MAGNITUDE(GM) = 2.5 \& LEARNING RATE(LR) = 0.01 ---> MODEL WILL CHANGE THE PARAMETER BY = 2.5(GM)\*0.01(LR) = 0.025



**BATCH SIZE -** IT'S A HYPERPARAMETER THAT REFERS TO THE NO. OF EXAMPLES THE MODEL PROCESSES BEFORE UPDATING WEIGHT \& BIAS. TWO COMMON TECHNIQUES USED TO GET THE RIGHT GRADIENT ON AVERAGE WITHOUT UPDATING THE WEIGHT \& BIAS ARE -

1. STOCHASTIC GRADIENT DESCENT (SGD)
2. MINI-BATCH STOCHASTIC GRADIENT DESCENT (mini-batch SGD)



* STOCHASTIC GRADIENT DESCENT (SGD) - IT USES A SINGLE EXAMPLE(BATCH SIZE=1) PER ITERATION. MULTIPLE ITERATION CHOOSEN RANDOMLY MAKES SGD WORK'S BUT IS VERY 'NOISY'. "NOISE" REFERS TO VARIATIONS DURING TRAINING THAT CAUSE THE LOSS TO INCREASE THE DECREASE DURING AN ITERATION.



* MINI-BATCH STOCHASTIC GRADIENT DESCENT - FOR N NUMBER OF DATA POINTS BATCH SIZE CAN BE ANY NUMBER GREATER THAN 1 AND LESS THAN N. THE MODEL CHOOSES THE EXAMPLE INCLUDED IN EACH BATCH AT RANDOM, AVERAGE THEIR GRADIENTS, AND UPDATE THEIR WEIGHT \& BIAS PER ITERATION.



NOISE HELP'S A MODEL TO GENERALIZE BETTER \& FIND THE OPTIMAL WEIGHTS \& BIAS IN A NEURAL NETWORK.



**EPOCHS-** EPOCHS MEANS THAT THE MODEL HAS PROCESSED EVERY EXAMPLE IN THE TRAINING SET ONCE. THE NUMBER OF EPOCHS IS A HYPERPARAMETER YOU SET BEFORE THE MODEL BEGINS TRAINING. HIGHER THE EPOCHS BETTER THE MODEL, HOWEVER GREATER THE TIME TO TRAIN. ONE EPOCH- A FULL BATCH COMPOSED OF 10 MINI-BATCHES.



BATCH TYPE				WHEN WEIGHTS AND BIAS UPDATES OCCUR (1000 EXAMPLES IN THE DATASET, MODEL TRAIN FOR 20 EPOCH)



1. FULL BATCH				AFTER THE MODEL LOOKS AT ALL THE EXAMPLES IN THE DATASET. MODEL UPDATES WEIGHT \& BIAS 20 TIMES PER EPOCH.

2\. STOCHASTIC GRADIENT DESCENT		AFTER THE MODEL LOOKS AT A SINGLE EXAMPLE FROM THE DATASET. MODEL UPDATES WEIGHT \& BIAS 20,000 TIMES.

3\. MINI-BATCG STOCHASTIC G-DESCENT	AFTER THE MODEL LOOKS AT THE EXAMPLES IN EACH BATCH. BATCH SIZE = 20 EPOCHS, WEIGHT \& BIAS UPDATED 200 TIMES.
