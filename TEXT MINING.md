TEXT PREPROCESSING-

* CLEANING \& NORMALIZATION
1. LOWERCASING
2. TOKENIZATION
3. REMOVE PUNCTUATIONS/SPECIAL CHARACTERS
4. REMOVE STOP WORDS
5. PoS(PART OF SPEECH) TAGGING
6. TOKENIZATION



* VECTORIZATION
1. BAG OF WORDS
2. TF-IDF(TERM FREQUENCY, INVERSE DOCUMENT FREQUENCY)



**TERM OF FREQUENCY**- NORMALIZE THE COUNT'S TO BRING ALL ON SAME SCALE

**INVERSE DOCUMENT FREQUENCY-** ASSIGN MORE WEIGHTS TO RARE WORDS THAN TO COMMON WORDS

TF-IDF = (TERM COUNT IN DOCUMENT/TOTAL TERMS IN DOCUMENT) \* LOG(TOTAL DOCUMENTS+1/DOCUMENTS WITH THE TERM+1)

**NON-NEGATIVE MATRIX FACTORIZATION(NMF)**

DECOMPOSES THE DOCUMENT TERM MATRIX INTO TWO OTHER MATRICES

* DOCUMENT TOPIC MATRIX(W) - IT SHOWS HOW MUCH EACH TOPIC APPEARS IN EACH DOCUMENT
* TOPIC-TERM MATRIX(H) - IT SHOWS HOW RELEVANT EACH WORD IS TO EACH TOPIC



TRADITIONAL NLP VS MODERN NLP

* TRADITIONAL NLP - SMALL TO MEDIUM DATA SET

TECHNIQUES - RULE BASED, SUPERVISED LEARNING(NAIVE BAYES), UNSUPERVISE(NON-NEGATIVE MATRIX FACTORIZATION)

APPLICATION - SENTIMENT ANALYSIS, TEXT CLASSIFICATION, TOPIC MODELING

* MODERN NLP - SMALL TO LARGE DATASET

TECHNIQUES - TRANSFORMER BASED LLMs(BERT,GPT,LLaMA,T5,BART)

APPLICATION - TRADITIONAL NLP APPLICATIONS, TEXT SUMMARIZATION, TEXT GENERATION



**NEURAL NETWORK** - INPUT LAYER(FEATURES) -> HIDDEN LAYER(PARAMETERS \& ACTIVATION FUNCTION) -> OUTPUT LAYERS(PREDICTIONS)

**ACTIVATION FUNCTION -**  IDENTITY, LOGISTIC, Tanh, ReLu

TRAINING A NEURAL NETWORK MEANS TO CALCULATE ITS OPTIMAL PARAMETERS

1. RANDOM FOREST - START WITH AN INITIAL SET OF RANDOM WEIGHTS \& BIASES
2. FORWARD PASS - APPLY ALL CALCULATION THROUGH NEURAL NETWORK TO GET TO FINAL SET OF PREDICTED VALUES
3. CALCULATE LOSS - COMPARE THE PREDICTED AND ACTUAL VALUES TO COMPUTE THE ERROR OR LOSS
4. UPDATE PARAMETERS - CALCULATE HOW MUCH EACH PARAMATER CONTRIBUTE TO THE LOSS WITH BACK PROPAGATION AND USE GRADIENT DESCENT TO ADJUST THE PARAMETER
5. REPEAT - REPEAT UNTIL IT MINIMIZE'S THE LOSS



DEEP LEARNING - USED FOR COMPLEX TASKS(NLP, CV, ASR); FOR LARGE DATASETS



**DEEP LEARNING ARCHITECTURES-**

* **CONVOLUTIONAL NEURAL NETWORK(CNNs) -** IMAGE RELATED TASKS LIKE IMAGE CLASSIFICATION, OBJECT DETECTION

RAW IMAGE -> CONVOLUTIONAL LAYER(EXTRACS IMAGE FEATURES) -> POOLING LAYER(REDUCES DIMENSIONS) -> FNN LAYER(LEARNS PATTERN) -> PREDICTION



* **RECURRENT NEURAL NETWORK(RNNs) -** SEQUENTIAL TASKS, SUCH AS NLP TASKS, TIME SERIES ANALYSIS

SEQUENTIAL DATA -> HIDDEN LAYERS(FEEDBACK LOOPS REMEMBER INFO FROM PRIOR STEPS) -> PREDICTION

LONG SHORT-TERM MEMORY(LSTMs)-> EXTENSION OF RNNs THAT INCLUDE LOGIC TO REMEMBER \& FORGET INFO OVER TIME



* **TRANSFORMERS -** NLP, CV, ASR TASKS; TRANSFORMERS HAVE REPLACED RNNs \& LSTMs FOR NLP TASK

RAW TEXT -> EMBEDDINGS LAYER -> ATTENTION LAYER -> FNN LAYER -> PREDICTION



THE TRANSFORMER ARCHITECTURE REFERS TO THE SERIES OF LAYERS \& COMPUTATIONS THAT THE INPUT DATA PASSES THROUGH TO PRODUCE A FINAL RESULT.

RAW TEXT -> EMBEDDING LAYERS -> ATTENTION LAYER -> FNN LAYER -> PREDICTION

* EMBEDDINGS LAYER - USES VECTORS TO REPRESENT THE SEMANTIC MEANING OF WORDS
* ATTENTION LAYER - ADJUSTS THEIR MEANINGS BASED ON CONTEXT FROM SURRONDING WORDS
* FNN LAYER - LEARNS PATTERNS FROM THE PRIOR LAYERS \& ADDS COMPLEXITY



**EMBEDDING LAYER -** THE FIRST LAYER OF A TRANSFORMER, THE EMBEDDINGS LAYERS, CONVERTS TEXT TOKENS INTO MEANINGFUL NUMERIC REPRESENTATIONS.

IT PLACES EACH TOKEN(WORD) INTO A HIGH-DIMENSIONAL SPACE, SO WORDS WITH SIMILAR MEANINGS ENDS UP CLOSE TOGETHER \& WORDS WITH DIFFERENT MEANINGS ARE FAR

DIMENSION VARY HOWEVER 768 IS A COMMON LENGTH FOR LLMs



**FNN(FEEDFORWARD NEURAL NETWORK) -** IT LEARNS PATTERNS FROM THE DATA \& ADDS COMPLEXITY TO THE MODEL

EMBEDDING LAYER - WORDS ARE PLACED IN LOCATIONS IN SPACE THAT HOLD SOME MEANING

ATTENTION LAYER - LOCATIONS ARE ADJUSTED BASED ON CONTEXT FROM SURRONDING WORDS

FNN LAYER - PATTERNS IN THOSE CONTEXTUAL RELATIONSHIPS ARE LEARNED \& CAPTURED



FNN IN A TRANSFORMER - INPUT LAYER -> HIDDEN LAYER -> OUTPUT LAYER

* OUTPUT IS A TRANSFORMED REPRESENTATION OF THE ORIGINAL TOKENS WITH REFINED MEANINGS
* ONE OF THE NODE COULD CAPTURE IDEA OF A NOUN-ADJECTIVE RELATIONSHIP AND OTHER THE CORE IDEA

ATTENTION LAYERS IN PARALLEL ARE KNOWN AS MULTI-HEADED ATTENTION



**ENCODER ONLY MODEL -** IT TAKES THE RAW TEXT \& ENCODES IT AS AN EMBEDDING REPRESENTATION OF THE TEXT. (UNDERSTANDS TEXT)

IT USES THE **LEFT SIDE OF THE ARCHITECTURE**, AKA THE ENCODER. EX.-SENTIMENT ANALYSIS

**DECODER ONLY MODEL -** THE DECODER TAKES AN INPUT TEXT SEQUENCE AND INFERS THE NEXT WORD.(GENERATES TEXT)

IT ONLY USES THE **RIGHT SIDE OF THE ARCHITECTURE**, AKA THE DECODER EX.-TEXT GENERATION



**ENCODER-DECODER MODEL -** THE ENCODER-DECODER TAKES TWO INPUTS - 1. TEXT SEQUENCE 2. SHIFTED TARGET SEQUENCE. BOTH ARE ENCODED AS EMBEDDINGS \& COMBINED TO INFER THE NEXT WORD(UNDERSTANDS TEXT \& GENERATES TEXT)

IT USES THE ARCHITECTURE BOTH THE ENCODER AND DECODER SIDES. EX-TRANSLATION



1. **ENCODER-ONLY LLMs** - TURNS TEXT INTO EMBEDDINGS, BERT-BIDIRECTIONAL ENCODER REPRESENTATIONS FROM TRANSFORMERS
2. **DECODER-ONLY LLMs** - INFERS THE NEXT TOKEN(WORD) IN A TEXT, GPT-GENERATIVE PRE-TRAINED TRANSFORMER
3. **ENCODER-DECODER LLMs** - TURNS TEXT INTO OTHER TEXT, T5- TEXT-TO-TEXT TRANSFER TRANSFORMER, BART-COMBINES BERT \& GPT



TRANSFORMER WORKFLOW-

1. DEFINE THE GOAL(SUMMARIZATION, GENERATION, SENTIMENT ANALYSIS)
2. IDENTIFY THE PRETRAINED MODEL (HUGGING FACE'S MODEL HUB)
3. SPECIFY YOUR INPUT DATA(SINGLE STRING, SERIES OR COLUMN)
4. APPLY THE PRETRAINED MODEL



* ENCODER ONLY - SENTIMENT ANALYSIS, NAMED ENTITY RECOGNITION
* DECODER ONLY - TEXT GENERATION
* ENCODER-DECODER - ZERO-SHOT CLASSIFICATION, TEXT SUMMARIZATION
* EMBEDDING - DOCUMENT SIMILARITY
